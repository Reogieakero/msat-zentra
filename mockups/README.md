# Zentra — Frontend Mockups

> Wireframe specs (Markdown, not images) for the Zentra web app. Grounded in:
> - `PLAN.md` §2 (Tailwind + shadcn/ui, **components only**) + design language
> - `docs/role-modules/*.md` (what each role sees / can do)
> - `zentra-design` skill (`frontend-design-direction.md`) — anti-generic tokens
>
> Tokens recap: bg `#FAFAF9`, surface white + 1px `#E7E5E4` border, ONE brand accent
> (school green/maroon/navy), `rounded-md`, display font (Geist/Space Grotesk) for
> headings + Inter body, monospaced for IDs/grades, micro-motion only.
>
> Each mockup: layout ASCII + component list (shadcn) + role actions from the spec.

- `principal-dashboard.md` — Principal module 1
